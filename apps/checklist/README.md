# Book checklist and scorecard

43 statements transcribed from the manuscript's five end-of-book saving checklist sections. Each answered applicable statement scores Yes=2, Partly=1, Not yet=0. Not applicable and unanswered statements are excluded from the denominator; unanswered reviews are provisional and no applicable answers produce no score. Category and overall scores describe self-reported practices, not financial health or eligibility. Focus suggestions put Not yet before Partly, retaining book order within each group.

Optional worksheet separates expense reductions from added support income, checks overlapping/excessive reductions, and displays estimated monthly/annual surplus and improvement. Unknown fields remain unknown until filled. Three custom actions and review dates are included in print. No persistence or network calls.

Serve the repository and run `APP_TEST_URL=http://localhost:8032 python apps/checklist/tests/browser.py` to check scoring, suggestions, estimates, printable output, reset and mobile layout.
