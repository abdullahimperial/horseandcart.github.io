# Original short-format Aiden editions

The portrait and teaser edits have separate scripts from the expanded landscape lessons. This branch renders Qwen3-TTS Aiden recordings for the first three numbered shorts, the introduction, and the second horse-and-cart edit. The catalog reads their existing repository scripts. The private production checkpoint carries the other original cuts and measured timelines.

Run catalog.py, then run_local.py /path/to/verified/kit shard.json. The four-part workflow follows the same process. The model, English speaker, style, per-line seeds, durations, and hashes are recorded for each output. Assemble the four disjoint artifact folders and match the IDs to the original master and caption times. Preserve the introduction’s background track. Do not mark a finished delivery from an audio build alone.

New chats can use the project-wide Aiden voice checkpoint and this branch together. Website releases and already-posted videos have independent status.
