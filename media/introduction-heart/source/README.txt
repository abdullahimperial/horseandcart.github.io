LET'S FIX MONEY — PORTRAIT YOUTUBE SHORT

28 seconds | 1080 x 1920 pixels | 9:16 portrait | 30 fps
Final format: H.264 MP4, AAC stereo, web fast-start enabled.

This edition is independently laid out for a phone screen. It is not a crop
or a letterboxed copy of the landscape video. Headlines are larger relative
to frame width. Key content is kept above the lower caption area and away
from the far right where Shorts controls are commonly displayed. Actual
overlays vary with device and YouTube interface.

Audio consists of original synthesized ticks, airy transitions and chimes.
There is no narration. All written messages remain understandable muted.
No bank information or real transaction data is used.

Assets
banner.png: matching portrait horse-and-cart artwork generated for this edit.
render_short.py: editable rendering source, including original sound design.

Rebuild
1. Install Python 3, FFmpeg, Pillow, NumPy and SciPy.
2. Install P052-Roman.otf and OpenSans-Regular.ttf, or update the SERIF and
   SANS font paths in render_short.py. On Debian/Ubuntu the relevant packages
   are fonts-urw-base35 and fonts-open-sans.
3. Keep render_short.py and banner.png together.
4. Run python3 render_short.py
   The MP4, WAV and review frames are created in the parent directory.
   For review frames only: python3 render_short.py --preview

The promotional wording is teaser copy, not a quotation from the manuscript.
