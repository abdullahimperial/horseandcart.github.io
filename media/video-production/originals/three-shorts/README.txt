Let’s Fix Money — Three continuous-scene Shorts

Run: python3 render.py --render 1 2 3
Preview: python3 render.py --preview

Requires Python 3, Pillow, NumPy, FFmpeg with libx264, and system Open Sans / DejaVu Sans fonts. Update font paths at the top for another system. No network or licensed stock media is used.

Each video has complete on-screen narration and original subtle sound effects. No synthetic spoken narration is included. The SRT files can be imported into an editor or uploaded as captions. Avoid displaying duplicate subtitles if the burned-in captions are enough.

The original manuscript is unchanged. The scripts are adaptations of Chapter 2. All values in the examples are illustrative. The third video resets to zero before showing the alternative negative path, then shows a debt repayment that improves net worth while it remains negative.
